## 📌 Sobre

Este repositório serve como **vitrine temporária** para projetos de presença online desenvolvidos para clientes em potencial. Cada subdiretório contém uma landing page ou site completo, otimizado para **SEO** e **PageRank acima de 90**, pronto para apresentação e validação.

A página raiz (`index.html`) exibe apenas um aviso de **"Em construção"** — ela **não é indexada** pelos mecanismos de busca, garantindo que apenas os projetos finalizados apareçam nos resultados de pesquisa.

---

## 🎯 Objetivos

| Meta | Descrição |

## 🤖 Política de Indexação (robots.txt)

A indexação segue uma regra clara:

- ❌ **Página raiz** (`/demo/index.html`) — **bloqueada** para mecanismos de busca
- ✅ **Todos os subdiretórios e seus arquivos** — **permitidos e indexáveis**

Isso garante que a página "Em construção" não apareça em resultados de busca, enquanto cada projeto-cliente é plenamente rastreável e ranqueável.

## 📝 Como Adicionar um Novo Projeto

1. Crie um subdiretório com o nome do cliente (ex.: `nome_do_cliente/`)
2. Adicione os arquivos do projeto (HTML, CSS, JS, assets)
3. Otimize as meta tags (title, description, OG, Twitter Cards)
4. Faça o commit e push para a branch `main`
5. O projeto estará disponível em `https://edusidegum.github.io/demo/nome_do_cliente/`
